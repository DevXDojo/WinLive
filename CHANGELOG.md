## Release Notes

### Version Numbering

WinLive follows [Semantic Versioning](https://semver.org/):

- **MAJOR** version for incompatible API changes
- **MINOR** version for backwards-compatible functionality additions
- **PATCH** version for backwards-compatible bug fixes

### Download

Downloads for all platforms are available on the [GitHub Releases](https://github.com/DevXDojo/WinLive/releases) page.

### Upgrade Notes

When upgrading from a previous version:

1. Your data is preserved in platform-specific directories
2. For major version upgrades, please review the changelog for breaking changes
